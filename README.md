## ⚠️ Important Note regarding Database Exercises

Some exercises in this repository involve database integration (MySQL). **These specific scripts will not run out of the box.**

To execute database-related exercises locally, you will need:
- A local database server running (e.g., via **WampServer** or similar).
- **MySQL Workbench** (or your preferred database client) to create and manage the schemas.
- To recreate the local tables and structures used during these practice sessions.
